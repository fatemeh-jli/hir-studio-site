## معرفی پروژه

**HIR Studio** یک پروژه طراحی و توسعه وب‌سایت فروشگاهی با محوریت محصولات دست‌ساز چوبی است. این پروژه با تمرکز بر طراحی رابط کاربری، تجربه خرید آنلاین، شخصی‌سازی محصولات و ایجاد تعامل میان کاربر و فضای فروشگاه توسعه داده شده است.

هدف پروژه، پیاده‌سازی یک تجربه فروشگاهی یکپارچه است؛ از مشاهده محصولات و بررسی جزئیات گرفته تا شخصی‌سازی، مدیریت سبد خرید و جریان ثبت سفارش.

این وب‌سایت به‌عنوان پروژه درس تجارت الکترونیک طراحی و پیاده‌سازی شده و شامل بخش‌های مختلف یک فروشگاه آنلاین، به همراه قابلیت‌های تعاملی و یک ویژگی مبتنی بر هوش مصنوعی است.

## قابلیت‌ها

### فروشگاه و محصولات

- نمایش مجموعه محصولات
- صفحات اختصاصی محصولات
- مشاهده تصاویر، مشخصات و قیمت محصولات
- تعامل با گزینه‌های خرید
- افزودن محصولات به سبد خرید

### سبد خرید و سفارش

- افزودن و حذف محصولات
- افزایش و کاهش تعداد محصولات
- محاسبه قیمت متناسب با تعداد و انتخاب‌ها
- پیاده‌سازی جریان ثبت سفارش

### شخصی‌سازی محصولات

امکان انتخاب ویژگی‌ها و گزینه‌های مختلف محصولات و مشاهده تغییرات مرتبط با انتخاب‌های کاربر در رابط کاربری.

### حساب کاربری

- رابط ورود و ثبت‌نام
- انتخاب آواتار
- صفحه پروفایل
- فرم اطلاعات شخصی

### AI Space Designer

قابلیتی مبتنی بر هوش مصنوعی که کاربر می‌تواند تصویر فضای داخلی خود را وارد کند تا رنگ‌های محیط بررسی شده و نوع چوب مناسب با فضای موردنظر پیشنهاد شود.

## طراحی رابط کاربری

طراحی وب‌سایت با رویکرد مینیمال و تمرکز بر نمایش محصولات انجام شده است. در طراحی صفحات تلاش شده است ساختار بصری یکپارچه، سلسله‌مراتب مناسب محتوا و هماهنگی میان اجزای مختلف رابط حفظ شود.

ویژگی‌های رویکرد طراحی:

- **Minimal Design:** استفاده از فضای خالی و پرهیز از شلوغی بصری
- **Visual Hierarchy:** ایجاد اولویت بصری برای محتوا و محصولات
- **Consistent UI:** هماهنگی رنگ‌ها، تایپوگرافی، فاصله‌ها و کامپوننت‌ها
- **Interactive Components:** ایجاد تعامل در بخش‌های مختلف فروشگاه
- **Responsive Layout:** طراحی متناسب با اندازه‌های مختلف صفحه

---

## توسعه و پیاده‌سازی

در فرایند توسعه، صفحات و کامپوننت‌های مختلف فروشگاه پیاده‌سازی شده و جریان‌های اصلی تعامل کاربر طراحی شده‌اند.

بخش‌های توسعه‌یافته شامل صفحات محصولات، سبد خرید، فرم‌های کاربری، رابط شخصی‌سازی محصول و قابلیت AI Space Designer هستند.

در این پروژه از ابزارهای هوش مصنوعی به‌عنوان ابزار کمکی در بخش‌هایی از فرایند توسعه، بررسی راه‌حل‌ها، رفع مشکلات و ایده‌پردازی استفاده شده است.

---

## وضعیت پروژه

نسخه فعلی شامل رابط کاربری و قابلیت‌های تعاملی اصلی فروشگاه است. با این حال، پروژه هنوز به دیتابیس و سیستم ذخیره‌سازی دائمی متصل نشده است.

در نتیجه، اطلاعات کاربران، سبد خرید و سفارش‌ها در حال حاضر به‌صورت دائمی ذخیره نمی‌شوند و پروژه برای تبدیل شدن به یک فروشگاه عملیاتی کامل به توسعه Backend و زیرساخت ذخیره‌سازی نیاز دارد.

## راه‌اندازی پروژه

### پیش‌نیازها

- Node.js
- npm

### نصب

```bash
git clone https://github.com/fatemeh-jli/hir-studio-site.git

cd hir-studio-site

npm install
```

### اجرای محیط توسعه

```bash
npm run dev
```

پس از اجرای پروژه، آدرس محلی نمایش‌داده‌شده در ترمینال را در مرورگر باز کنید.

در صورت نیاز به متغیرهای محیطی، فایل `.env` را مطابق تنظیمات پروژه ایجاد کنید.
