## درباره پروژه

**HIR Studio (هیر استودیو)** یک فروشگاه آنلاین مفهومی برای محصولات دست‌ساز چوبی است که با هدف ایجاد تجربه‌ای فراتر از خرید اینترنتی طراحی و توسعه داده شده است.

در هیر، کاربر تنها با یک فروشگاه محصولات روبه‌رو نیست؛ بلکه می‌تواند محصولات را بررسی کند، ویژگی‌های آن‌ها را شخصی‌سازی کند، برای فضای زندگی خود پیشنهاد بگیرد و با هویت و داستان برند ارتباط برقرار کند.

این پروژه به‌عنوان پروژه درس تجارت الکترونیک توسعه داده شده و شامل طراحی هویت برند، رابط کاربری، تجربه کاربری و پیاده‌سازی قابلیت‌های تعاملی فروشگاه است.

---

## هویت برند

نام **Hir (هیر)** از مفاهیم مرتبط با جوهر، ماهیت و بخش ارزشمند چوب الهام گرفته شده است.

هویت بصری پروژه با تأکید بر اصالت متریال، فرم‌های مینیمال، خطوط نرم و طراحی معاصر شکل گرفته است. هدف، ایجاد فضایی آرام و متمرکز بر خود محصول است؛ فضایی که جزئیات چوب و طراحی، بدون عناصر بصری اضافه دیده شوند.

## قابلیت‌ها

### فروشگاه

- نمایش محصولات و مجموعه‌ها
- صفحات اختصاصی محصولات
- مشاهده جزئیات و قیمت
- افزودن محصولات به سبد خرید
- تغییر تعداد محصولات
- محاسبه قیمت بر اساس تعداد و گزینه‌های انتخابی
- جریان ثبت سفارش

### شخصی‌سازی محصول

امکان انتخاب گزینه‌ها و ویژگی‌های محصول و مشاهده تأثیر انتخاب‌ها بر محصول و قیمت نهایی.

### AI Space Designer

قابلیتی برای دریافت تصویر فضای کاربر و تحلیل رنگ‌های محیط، با هدف پیشنهاد نوع چوب هماهنگ با فضای داخلی.

### حساب کاربری

- ثبت‌نام
- ورود
- انتخاب آواتار
- صفحه پروفایل
- فرم اطلاعات شخصی

## ساختار و رویکرد طراحی

در طراحی هیر، تمرکز اصلی بر کاهش شلوغی بصری و ایجاد یک تجربه یکپارچه بوده است.

- **Minimal UI:** حذف عناصر غیرضروری و حفظ فضای تنفس در صفحات
- **Visual Hierarchy:** هدایت توجه کاربر به محصولات و محتوای مهم
- **Consistent Design System:** استفاده هماهنگ از رنگ‌ها، تایپوگرافی، فاصله‌ها و عناصر رابط
- **Interactive Experience:** ایجاد تعامل در شخصی‌سازی محصولات و فرایند خرید
- **Brand Consistency:** حفظ هویت بصری در صفحات مختلف فروشگاه

---

## توسعه پروژه و استفاده از هوش مصنوعی

در فرایند توسعه، از ابزارهای هوش مصنوعی به‌عنوان ابزار کمکی برای ایده‌پردازی، پیاده‌سازی بخش‌هایی از کد، بررسی راه‌حل‌ها و رفع مشکلات فنی استفاده شده است.

در کنار توسعه فنی، طراحی هویت برند، انتخاب سبک بصری، ایده‌پردازی تجربه کاربری، ساختار صفحات و توسعه مفهوم پروژه در طول فرایند شکل گرفته است.

همچنین قابلیت AI Space Designer یکی از بخش‌های تعاملی خود سایت است که از هوش مصنوعی در تجربه انتخاب محصول استفاده می‌کند.

---

## وضعیت فعلی پروژه

قابلیت‌های اصلی رابط فروشگاه پیاده‌سازی شده‌اند؛ از جمله مشاهده محصولات، شخصی‌سازی، سبد خرید، تغییر تعداد، ثبت سفارش و جریان‌های ورود و ثبت‌نام.

با این حال، نسخه فعلی پروژه به دیتابیس متصل نیست و اطلاعات به‌صورت دائمی ذخیره نمی‌شوند. بنابراین پروژه هنوز به زیرساخت Backend و ذخیره‌سازی دائمی برای استفاده در محیط واقعی نیاز دارد.

## اجرا در محیط توسعه

### پیش‌نیازها

- Node.js
- npm

### نصب

```bash
git clone https://github.com/fatemeh-jli/hir-studio-site.git

cd hir-studio-site

npm install
```

### اجرا

```bash
npm run dev
```

سپس آدرس محلی نمایش داده‌شده در ترمینال را در مرورگر باز کنید.

> در صورت نیاز به متغیرهای محیطی، مقادیر موردنیاز را در فایل `.env` مطابق ساختار پروژه تنظیم کنید.
